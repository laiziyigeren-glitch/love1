# 相册沉浸展示功能设计方案

## 目标

给相册页增加一个“回忆放映”功能，让已经上传到相册里的照片、视频、实况图可以自动组成一个更有氛围的展示空间。这个功能不重新上传素材，也不要求用户再填一遍内容，直接读取当前相册页面已经有的数据。

参考文件里的效果是一个独立 HTML 相册，核心是 3D 环形照片墙、拖拽旋转、滚轮缩放和飘花氛围。我们可以借它的“沉浸展示”思路，但不能直接照搬：它依赖本地图片路径、外部 jQuery、黑底风格，和现在网站的 R2 媒体、视频、实况图、隐私权限、整体玫瑰夜景风格都不完全匹配。

## 功能名称

推荐按钮文案：`回忆放映`

备选：

- `记忆星河`
- `时光放映`
- `沉浸相册`

推荐用 `回忆放映`，因为它最直观，用户一看就知道是点开播放相册内容。

## 按钮放置位置

### 桌面端

放在相册页顶部工具栏右侧，和排序、上传按钮在同一行。

建议结构：

```text
[全部] [照片] [视频] [实况] [收藏]          [回忆放映] [排序下拉] [上传照片]
```

原因：

- 它属于相册页的操作，不适合放到全站导航栏。
- 放在上传按钮附近，用户刚上传照片后自然会想到“看看效果”。
- 不会挤占相册卡片区域，也不会破坏当前页面布局。

### 移动端

优先放在相册顶部工具栏第二行，使用紧凑按钮。

建议结构：

```text
[全部] [照片] [视频] [实况] [收藏]
[回忆放映] [排序]
```

如果移动端空间不足，可以只显示图标加短文字：`播放`。不建议再额外加一个悬浮按钮，因为相册页已经有上传入口，两个悬浮按钮会抢视觉焦点。

### 空相册状态

如果没有可展示内容，按钮禁用，并显示轻提示：

```text
上传照片后，就可以开启回忆放映。
```

## 数据来源

第一阶段不新增数据库字段，不改后台。

展示内容直接来自前台相册当前数据：

- 来源：`spaceData.albumItems`
- 默认使用当前相册筛选后的列表
- 当前正在看“全部”，就播放全部可见内容
- 当前正在看“收藏”，就只播放收藏内容
- 当前正在看某个分类，优先播放这个分类里的内容

每个展示项复用现有相册数据字段：

- 图片：使用 `url` 或缩略图地址
- 视频：使用封面图或视频地址
- 实况图：优先展示封面，聚焦时播放短动态
- 标题、日期、描述：作为轻量字幕，不做大段文字遮挡

隐私规则保持一致：前台当前能看到什么，放映里才展示什么。不要绕过现有私密相册逻辑。

## 展示形式

### 推荐第一版：记忆星河

打开后进入一个全屏沉浸层，不替换原本相册列表。

视觉方向：

- 背景使用当前主图的柔化大背景，叠加网站本身的暗红玻璃质感
- 中央展示当前照片或视频封面
- 周围漂浮 4 到 8 张小照片，形成轻微纵深
- 切换时使用淡入、轻微缩放、慢速位移
- 保持玫瑰色、酒红色、金色点缀，和现有页面统一

交互：

- 自动播放
- 上一张 / 下一张
- 暂停 / 继续
- 关闭
- 速度：慢 / 标准 / 快
- 桌面端支持左右方向键切换、`Esc` 关闭

这个版本比直接做 3D 环形相册更稳，移动端也更容易好看。

### 第二版增强：环形回忆

在桌面端增加 3D 环形照片墙模式。

特点：

- 图片围成一个柔和圆环
- 中间焦点图最清晰
- 鼠标拖动可以轻轻旋转
- 滚轮可以调整远近

注意：

- 移动端不要强行做复杂 3D，容易卡顿和误触
- 开启低性能或减少动态效果时，自动退回“记忆星河”

### 第三版增强：时间胶片

适合照片很多的时候。

特点：

- 按日期或上传顺序形成横向胶片
- 当前照片在中间放大
- 下方显示一条小时间线
- 可以快速拖动浏览一段时间里的回忆

## 视频和实况图处理

### 视频

视频默认作为一个展示项出现。

第一版建议：

- 自动放映时先显示视频封面
- 用户点当前视频后再播放
- 不自动播放声音，避免浏览器限制和突然出声

后续可以支持：

- 聚焦到视频时静音预览 3 秒
- 点播放后进入视频观看状态

### 实况图

实况图可以显示一个小标识。

第一版建议：

- 默认显示封面图
- 当它成为当前主图时，播放一小段静音动态
- 如果实况图没有动态资源，就当普通照片展示

## UI 细节

### 入口按钮

按钮样式建议使用半透明玻璃胶囊按钮：

```text
[闪光图标] 回忆放映
```

颜色不要太亮，和当前相册按钮保持统一：

- 背景：暗红半透明
- 边框：玫瑰色细线
- 文字：浅粉白
- hover：轻微提亮，不要大面积渐变

### 全屏展示层

展示层结构建议：

```text
顶部：标题 / 当前序号 / 关闭
中间：主照片 + 周围漂浮照片
底部：上一张 / 播放暂停 / 下一张 / 速度 / 模式
```

不要做成很多卡片嵌套。它应该像一个沉浸放映厅，而不是新的管理面板。

### 字幕

字幕只显示短信息：

- 标题
- 日期
- 一句描述

长描述可以折叠，不要压在图片上影响观看。

## 动效原则

动效要温柔，不要吵。

推荐：

- 缓慢漂浮
- 淡入淡出
- 轻微景深
- 当前图片慢慢放大一点点

避免：

- 快速旋转
- 大幅度弹跳
- 过多粒子
- 每张图都剧烈翻转

同时需要支持 `prefers-reduced-motion`：如果用户系统设置减少动态，就关闭漂浮和缩放，只保留淡入淡出。

## 实现阶段

### 第一阶段：设计文档

当前阶段只确定功能范围、入口位置、数据来源和展示形式。

### 第二阶段：前台 MVP

只改 `you-and-me.html`。

改动范围：

- 相册工具栏增加 `回忆放映` 按钮
- 增加全屏展示层 DOM
- 增加展示层 CSS
- 增加展示状态：
  - 是否打开
  - 当前索引
  - 是否自动播放
  - 播放速度
- 根据当前相册筛选结果生成展示列表
- 加入上一张、下一张、播放暂停、关闭
- 支持键盘 `Esc`、左右方向键

验证：

- `npm run build:web`

### 第三阶段：增强模式

增加：

- 桌面端 3D 环形展示
- 时间胶片模式
- 视频静音预览
- 实况图聚焦播放
- 收藏照片优先展示选项

### 第四阶段：后台配置

如果后面想让后台控制默认效果，可以新增相册展示设置。

可能配置：

- 默认展示模式
- 默认播放速度
- 是否开启漂浮效果
- 是否优先播放收藏
- 是否显示视频
- 是否显示实况图

这一步再考虑数据库或设置字段，不建议第一版就加，避免把简单功能做重。

## 风险和处理

### 图片太多导致卡顿

处理方式：

- 每次只预加载当前、上一张、下一张
- 周围漂浮缩略图最多 8 张
- 优先用缩略图

### 移动端 3D 效果不稳定

处理方式：

- 移动端第一版只用“记忆星河”
- 3D 环形只在桌面端开启

### 视频自动播放受限制

处理方式：

- 不自动播放声音
- 默认显示封面
- 用户手动点开再播放

### 私密内容误展示

处理方式：

- 放映列表只使用当前前台已经过滤后的相册数据
- 不单独请求隐藏内容

## 验收标准

- 相册页能看到不突兀的 `回忆放映` 按钮
- 点击后进入全屏展示层
- 展示内容来自当前相册已有照片、视频、实况图
- 自动播放、暂停、上一张、下一张、关闭都可用
- 空相册不会报错
- 一张图、两三张图、很多张图都能正常展示
- 移动端不会遮挡上传、筛选、关闭按钮
- 不影响原来的相册上传、预览、筛选、收藏功能
- 构建通过：`npm run build:web`

## 推荐下一步

下一步建议先做第二阶段的前台 MVP：只加一个 `回忆放映` 入口和一个稳定好看的“记忆星河”展示层。等这个版本在手机和电脑上都好看，再继续做 3D 环形和时间胶片模式。
